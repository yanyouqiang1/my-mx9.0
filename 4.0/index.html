🔑 LOGO 键快捷操作

通过 LOGO 键的不同按压时长触发不同功能

🎯 单击 ( < 2秒)

切换 CHERRY_LOGO 灯效模式（开启/关闭），并执行已配置的 LOGO 宏

🔄 长按 2-8 秒

发送 N_REBOT 信号 → C3 显示重启动画 → 键盘普通重启

⚡ 长按 ≥ 8 秒

发送 N_ROOT 信号 → 强制进入 ROM 刷机模式

🔔 系统通知与优先级

C3 灯光优先级层级，高优先级可覆盖低优先级效果

L0

物理强关 (g_forceOff)

长按灯光键 2 秒 → 强制关闭所有灯光，任何其他效果都无法覆盖

L1

蓝牙提示闪烁 (bt_alert)

收到蓝牙 R/G/B/Y 指令 → 对应颜色闪烁，可覆盖常规灯效

L2

系统通知动画 (sysState)

N_ME(记忆更新) / N_REBOT(重启) / N_ROOT(刷机) 特殊动画序列

L3

按键扩散特效 (isRippleActive)

按下任意键时触发的环形扩散动画，颜色可选

L4

常规背景灯效 (currentEffect)

默认显示的 14 种灯效模式 (Mode 0-13)

串口通知指令表

💾

N_ME 记忆更新

S3 宏配置完成，触发记忆更新完成动画

黄青交替爆闪
🔄

N_REBOT 普通重启

LOGO 长按 2-8 秒触发，系统正常重启

红→绿→蓝→白 过渡
⚡

N_ROOT 刷机模式

LOGO 长按 ≥8 秒，强制进入 ROM 刷机

橙色持续闪烁
👆

N_KEY_PRESS 按键按下

S3 检测到按键按下，触发扩散特效

环形扩散动画
