# S3 蓝牙音频网关功能设计

## 概述

将 S3 模拟成一个蓝牙耳机中转网关：
- 蓝牙耳机连接 S3
- S3 将音频输出到电脑（耳机→电脑）
- S3 将电脑音频输入到耳机（电脑→耳机）
- 无蓝牙的电脑也能通过 S3 使用蓝牙耳机

## 技术方案

### 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        S3 主循环                             │
├───────────────────────┬─────────────────────────────────────┤
│   键盘扫描模块         │   音频网关模块（独立任务）            │
│   (现有代码)           │   ┌──────────────┬────────────────┐ │
│                       │   │ BLE A2DP     │ USB Audio      │ │
│                       │   │ (耳机端)     │ (电脑端)       │ │
│                       │   └──────┬───────┴───────┬────────┘ │
│                       │          │ Ring Buffer   │          │
│                       │          └───────────────┘          │
└───────────────────────┴─────────────────────────────────────┘
```

### 技术选型

| 组件 | 技术方案 | 说明 |
|------|----------|------|
| BLE 协议栈 | NimBLE (ESP-IDF 内置) | A2DP Sink + HFP Audio Gateway |
| USB 音频 | TinyUSB | USB Audio Device Class |
| USB 复合设备 | 键盘 + 音频复合 | 修改 USB 描述符 |

### 音频参数

- 采样率：48kHz
- 位深：16-bit
- 声道：立体声（播放）/ 单声道（录音）
- 缓冲区：Ring Buffer 16KB

## 功能模块

### 1. BLE 音频模块

**角色：**
- A2DP Sink：接收蓝牙耳机音频流
- HFP Audio Gateway：接收/发送语音通话

**状态：**
- `BT_AUDIO_OFF`：蓝牙音频功能关闭
- `BT_AUDIO_SCANNING`：扫描中
- `BT_AUDIO_CONNECTED`：已连接耳机
- `BT_AUDIO_PLAYING`：正在播放

**功耗控制：**
- 关闭时：停止 BLE 广播和音频服务
- 打开时：启动 BLE 广播，等待连接

### 2. USB 音频模块

**功能：**
- USB Audio Device：模拟 USB 声卡
- 播放：接收电脑音频，通过 BLE 发送给耳机
- 录音：接收耳机麦克风音频，发送给电脑

**设备识别：**
- VID: 0x303A
- PID: 0x0020（新增或修改现有）
- 设备名称：YYQ-MX9.0 Audio

### 3. 数据流

**播放流（耳机→电脑）：**
```
蓝牙耳机 → BLE A2DP → Ring Buffer → USB Audio OUT → 电脑
```

**录音流（电脑→耳机）：**
```
电脑 → USB Audio IN → Ring Buffer → BLE HFP → 蓝牙耳机
```

### 4. 配对信息存储

**存储内容：**
- 已配对设备列表（名称、MAC 地址、安全密钥）
- 最近连接的设备
- 配对状态

**存储位置：**
- Preferences（Flash）

### 交互流程

1. **开关控制**：点击开关启用/禁用蓝牙音频功能
2. **扫描**：点击按钮扫描附近蓝牙耳机，显示列表
3. **配对连接**：点击设备名称进行配对和连接
4. **已配对设备管理**：显示已配对设备列表，支持一键连接/断开/删除

## 按键控制

**物理按键：**
- 长按特定宏键（如 ME）打开/关闭蓝牙音频功能
- LED 指示状态

**状态指示：**
- 通过 Serial1 向 C3 发送状态，C3 控制 LED

## BLE 通讯扩展

**新增 BLE Service：**
- Service UUID: `4fafc201-1fb5-459e-8fcc-c5c9c331914c`（音频配置）
- Characteristics:
  - `bt_audio_enable`: 1 byte (0=关闭, 1=开启)
  - `bt_audio_status`: 1 byte (状态)
  - `bt_audio_command`: 1 byte (命令：扫描、连接、断连)

## 测试计划

1. **基础连接测试**：S3 广播，被手机/耳机发现
2. **配对测试**：网页扫描、选择、配对
3. **音频播放测试**：耳机→S3→电脑播放
4. **音频录音测试**：电脑→S3→耳机播放
5. **复合设备测试**：键盘+声卡同时工作
6. **功耗测试**：开关功能验证

## 风险与限制

1. **USB 复合设备兼容性**：部分电脑可能需要安装驱动
2. **音频延迟**：预期 50-100ms 延迟
3. **BLE 连接稳定性**：需要测试不同品牌耳机兼容性
4. **Flash 写入寿命**：配对信息频繁写入需注意

## 优先级

| 阶段 | 功能 | 说明 |
|------|------|------|
| P0 | USB 复合设备配置 | 修改 USB 描述符 |
| P0 | BLE 基础连接 | 广播、扫描、配对 |
| P0 | 音频播放通路 | 耳机→电脑 |
| P1 | 音频录音通路 | 电脑→耳机 |
| P1 | 网页界面 | 配置和状态显示 |
| P2 | 按键控制 | 物理开关 |
