# ESP32-E3/S3/C3 蓝牙音频架构设计

## 1. 系统概述

### 1.1 目标
在现有 MX9.0 键盘（S3 + C3）基础上，新增 ESP32-E3 作为蓝牙音频接收器，实现：
- 蓝牙耳机连接（支持 A2DP 音乐播放 + HFP 通话）
- 电脑 USB 音频设备输出（S3 模拟 USB Speaker + USB Mic）
- 键盘功能与音频功能同时工作（复合设备）

### 1.2 硬件架构

```
┌─────────────┐     I2S Audio      ┌─────────────┐    USB Audio     ┌─────────────┐
│   E3(E3)    │ ──────────────────→ │   S3(S3)    │ ───────────────→ │   电脑      │
│  Bluetooth  │                     │  USB Audio  │                   │  USB Speaker│
│  Audio Hub  │     UART Control   │  + Keyboard │                   │  + Mic      │
│  + A2DP     │ ←─────────────────→ │  Composite  │                   │  + HID      │
│  + HFP      │                     │             │                     │             │
└─────────────┘                     └─────────────┘                   └─────────────┘
                                           ↑
                                           │ UART (115200)
                                           ↓
                                    ┌─────────────┐
                                    │   C3(C3)    │
                                    │  LED控制    │
                                    │  旋钮编码   │
                                    └─────────────┘
```

### 1.3 芯片角色

| 芯片 | 主要功能 | 通信接口 |
|------|---------|---------|
| **E3** | 蓝牙音频接收、解码、I2S输出、控制命令交互 | I2S Master (TX), UART (控制) |
| **S3** | USB HID 键盘 + USB Audio 复合设备、I2S Slave (RX) | I2S Slave (RX), USB Device, UART→C3 |
| **C3** | RGB LED 灯效控制、旋钮/按键输入 | UART→S3 |

## 3. 通信协议

### 3.1 E3 ↔ S3 控制命令 (UART, 115200 baud, 8N1)

E3 主动上报 → S3:

| 命令 | 格式 | 说明 |
|------|------|------|
| 蓝牙连接成功 | `BT_CONNECTED:<设备名>` | 蓝牙耳机已连接 |
| 蓝牙断开 | `BT_DISCONNECTED` | 蓝牙耳机断开 |
| 播放状态变更 | `BT_PLAYBACK:<playing\|paused\|stopped>` | 播放状态 |
| 收到电话 | `BT_CALL:incoming` | 来电 |
| 通话状态 | `BT_CALL:<active\|ended>` | 通话开始/结束 |
| 音乐信息 | `BT_INFO:<艺术家>:<歌曲名>` | 可选 |
| 采样率 | `AUDIO_RATE:<48000\|44100\|32000>` | 采样率通知 |

S3 主动发送 → E3:

| 命令 | 格式 | 说明 |
|------|------|------|
| 播放/暂停 | `CTRL_PLAYPAUSE` | 同步电脑端播放状态 |
| 下一首 | `CTRL_NEXT` |  |
| 上一首 | `CTRL_PREV` |  |
| 音量调节 | `CTRL_VOLUME:<0-100>` | 音量百分比 |

### 3.2 E3 → S3 音频数据 (I2S)

- **格式**: 16-bit PCM, 48kHz, 立体声 (I2S 标准格式)
- **数据流向**: E3 I2S TX → S3 I2S RX
- **时钟**: E3 作为 Master，提供 BCK 和 WS
- **协议**: 标准 I2S 协议，左声道在前

### 3.3 S3 → C3 串口命令 (无变化)

| 命令 | 方向 | 说明 |
|------|------|------|
| `V+`, `V-` | S3→C3 | 音量调节 |
| `N_ME` | S3→C3 | 记忆更新完成 |
| `N_REBOT` | S3→C3 | 键盘重启 |
| `N_ROOT` | S3→C3 | 进入刷机模式 |
| `N_KEY_PRESS` | S3→C3 | 键盘按键触发灯效 |

## 4. 功能模块

### 4.1 E3 固件模块

#### 4.1.1 蓝牙模块 (Bluetooth)
- **A2DP Sink**: 接收蓝牙耳机发送的音频流
- **AVRCP**: 控制指令（播放/暂停/切歌）
- **HFP**: 通话音频接收
- **自动重连**: 记忆上次配对设备，断电后自动连接

#### 4.1.2 音频解码模块
- 接收 A2DP SBC/AAC/aptX 数据包
- 解码为 PCM
- 通过 I2S 输出

#### 4.1.3 I2S 输出模块
- 配置为 I2S Master
- 输出格式: 16-bit, 48kHz, 立体声
- 44.1kHz 自动重采样（蓝牙常用 44.1k）

#### 4.1.4 控制命令模块
- 解析 S3 下发的控制命令
- 控制蓝牙播放状态
- 上报设备状态

#### 4.1.5 LED 指示模块
- GPIO10 连接状态指示灯
- 快闪 = 配对中
- 慢闪 = 已连接
- 双闪 = 通话中

### 4.2 S3 固件模块（新增）

#### 4.2.1 USB Audio 复合设备
- **USB HID Keyboard** (原有)
- **USB Speaker**: 接收 I2S 音频，透传到电脑
- **USB Microphone**: 采集电脑音频（静音处理，因为无上行音频源）

#### 4.2.2 I2S 接收模块
- 配置为 I2S Slave
- 接收 E3 的 PCM 数据
- 缓存+USB 转发

#### 4.2.3 串口控制模块
- 与 E3 交换控制命令
- 与 C3 交换键盘/灯效命令

#### 4.2.4 音频路由模块
- 检测 E3 连接状态
- 音频播放时自动路由到电脑
- 断开时静音

### 4.3 C3 固件模块（无变化）

- WS2812 灯效控制
- 旋钮编码器处理
- 物理按键处理
- 与 S3 串口通信

## 5. 数据流

### 5.1 音乐播放流程

```
蓝牙耳机 → (A2DP) → E3 蓝牙模块 → PCM解码 → I2S输出 → S3 I2S输入 → USB Audio TX → 电脑扬声器
```

### 5.2 通话流程（下行）

```
蓝牙耳机 → (HFP) → E3 蓝牙模块 → PCM解码 → I2S输出 → S3 I2S输入 → USB Audio TX → 电脑麦克风输入
```

### 5.3 通话流程（上行）

```
电脑麦克风输入 → S3 USB Audio RX → (丢弃/静音) → (无上行)
※ 当前设计不支持上行通话音频，因为蓝牙耳机麦克风数据无法回传到电脑
```

## 6. 状态机

### 6.1 E3 蓝牙状态机

```
[IDLE] → (配对命令) → [PAIRING] → (连接成功) → [CONNECTED]
[CONNECTED] → (断开) → [IDLE]
[CONNECTED] → (播放) → [PLAYING]
[PLAYING] → (暂停) → [CONNECTED]
[CONNECTED] → (来电) → [RINGING]
[RINGING] → (接听) → [IN_CALL]
[IN_CALL] → (挂断) → [CONNECTED]
```

### 6.2 S3 音频路由状态机

```
[AUDIO_IDLE] → (E3 BT_CONNECTED) → [AUDIO_READY]
[AUDIO_READY] → (E3 PLAYING) → [AUDIO_STREAMING]
[AUDIO_STREAMING] → (E3 PAUSED) → [AUDIO_READY]
[AUDIO_*] → (E3 DISCONNECTED) → [AUDIO_IDLE]
```

## 7. 错误处理

### 7.1 E3 错误处理
| 错误 | 处理方式 |
|------|---------|
| 蓝牙配对失败 | LED 红色快闪3次，重试 |
| I2S 总线错误 | 复位 I2S，重新初始化 |
| UART 命令解析错误 | 忽略，丢弃错误数据 |
| 蓝牙音频卡顿 | 启用内部 Buffer 缓冲 |

### 7.2 S3 错误处理
| 错误 | 处理方式 |
|------|---------|
| I2S 无信号 | 输出静音，防止爆音 |
| USB 音频断开 | 静默处理，保持键盘功能 |
| E3 断开连接 | 停止音频路由，保持键盘功能 |
| C3 通信超时 | 保持灯效状态，不影响键盘 |

## 10. 设计约束

1. **延迟容忍**: 蓝牙音频本身有 ~150ms 延迟，系统应尽量不增加额外延迟
2. **功耗**: E3 保持低功耗蓝牙模式
3. **兼容性**: S3 USB 复合设备需要在 Windows/macOS/Linux 上免驱识别
4. **稳定性**: 蓝牙连接断开后应自动重连，不影响键盘功能
5. **上行音频**: 当前设计不支持蓝牙耳机麦克风到电脑的上行通路
