# E3 蓝牙音频网关设计文档

## 1. 概述

E3是基于ESP32-C3的蓝牙音频网关模块，与S3（USB声卡+键盘主控）配合，实现电脑音频通过蓝牙耳机播放，以及蓝牙耳机麦克风录音的功能。

### 1.1 系统架构

```
电脑USB音频 ──► S3(I2S输出) ──► E3(I2S输入) ──► 蓝牙A2DP ──► 蓝牙耳机(播放)
电脑USB麦克风 ◄── S3(I2S输入) ◄── E3(I2S输出) ◄── 蓝牙A2DP ◄── 蓝牙耳机(录音)
                                          ▲
                                    INMP441麦克风(可切换)
```

### 1.2 模块角色

| 模块 | 芯片 | 功能 |
|------|------|------|
| S3 | ESP32-S3 | 主键盘控制器 + USB声卡(播放+录音) + I2S音频 + UART控制E3 |
| C3 | ESP32-C3 | LED控制器 + 旋钮 + 按钮长按控制S3 + 蓝牙OTA |
| E3 | ESP32-C3 | 蓝牙音频网关 + OLED屏幕 + 温湿度传感器 + 麦克风切换 + 蓝牙OTA |

## 2. S3 ↔ C3 通信（现有UART）

### 2.1 硬件连接

| 方向 | S3引脚 | C3引脚 | 信号 |
|------|--------|--------|------|
| S3 TX → C3 RX | GPIO 9 | GPIO 10 | 命令 |
| S3 RX ← C3 TX | GPIO 10 | GPIO 20 | 命令 |

- 波特率：115200，8N1

### 2.2 命令协议

| 命令 | 方向 | 说明 |
|------|------|------|
| `V+` | C3→S3 | 旋钮右旋，音量增加 |
| `V-` | C3→S3 | 旋钮左旋，音量减少 |
| `N_S3_REBOT` | C3→S3 | 长按Mute 3-8秒，S3普通重启 |
| `N_S3_ROOT` | C3→S3 | 长按Mute 8秒+ 或 长按CPG 3秒+，S3进入串口刷机模式 |

---

## 3. S3 ↔ E3 通信（新增）

### 3.1 硬件连接

**I2S音频接口（双向）**

| 功能 | S3引脚 | E3引脚 |
|------|--------|--------|
| BCLK | GPIO 11 | GPIO 3 |
| WS | GPIO 12 | GPIO 2 |
| DOUT(播放) | GPIO 13 | GPIO 1 |
| DIN(录音) | GPIO 14 | GPIO 4 |

**UART控制接口**

| 方向 | S3引脚 | E3引脚 | 波特率 |
|------|--------|--------|--------|
| S3 TX → E3 RX | GPIO 5 | GPIO 6 | 115200 |
| S3 RX ← E3 TX | GPIO 6 | GPIO 5 | 115200 |

### 3.2 UART命令协议

| 命令 | 方向 | 说明 |
|------|------|------|
| `AUDIO_SRC_BT` | S3→E3 | 切换到蓝牙麦克风 |
| `AUDIO_SRC_LOCAL` | S3→E3 | 切换到INMP441本地麦克风 |
| `BT_CONNECTED` | E3→S3 | 蓝牙已连接（可选状态报告） |
| `BT_DISCONNECTED` | E3→S3 | 蓝牙已断开（可选状态报告） |

## 4. E3 引脚定义

| 功能 | 引脚 | 说明 |
|------|------|------|
| I2S BCLK | GPIO 3 | I2S位时钟 |
| I2S WS | GPIO 2 | I2S字选择 |
| I2S DOUT | GPIO 1 | I2S播放数据输出 |
| I2S DIN | GPIO 4 | I2S录音数据输入 |
| UART TX | GPIO 5 | 控制命令发送 |
| UART RX | GPIO 6 | 控制命令接收 |
| I2C SDA | GPIO 7 | OLED + SHT31共用 |
| I2C SCL | GPIO 8 | OLED + SHT31共用 |

## 5. E3 功能模块

### 5.1 蓝牙A2DP音频

- **设备名称**：YYQ-BT-Audio
- **A2DP Sink**：接收手机/电脑音频，通过I2S输出到S3
- **A2DP Source**：将蓝牙耳机麦克风录音通过I2S输入到S3
- **AVRCP控制**：支持播放/暂停/上一首/下一首命令

### 5.2 音频源切换

E3支持两种录音源，通过S3发送UART命令切换：

| 模式 | 音频路径 |
|------|----------|
| 蓝牙麦克风 | 蓝牙耳机MIC → A2DP → E3 → I2S → S3 |
| 本地麦克风 | INMP441 → E3 → I2S → S3 |

### 5.3 OLED显示（SSD1306 128x64 I2C）

显示内容：
- 蓝牙连接状态（已连接/未连接）
- 当前音频源（BT MIC / Local MIC）
- 温湿度（每5秒更新）
- 播放状态图标

### 5.4 温湿度传感器（SHT31 I2C）

- 每5秒读取一次
- 显示在OLED屏幕上
- 精度：温度±0.3℃，湿度±2%RH

### 5.5 蓝牙OTA升级

- 使用ESP32 BLE OTA方案
- 服务UUID：`0000FFFF-0000-1000-8000-00805F9B34FB`
- 特性UUID：`<auto-generated>`

## 6. C3 长按控制逻辑

参考S3的LOGO键长按逻辑实现。

### 6.1 Mute按钮

| 按下时长 | 行为 |
|----------|------|
| < 3秒 | 静音切换（当前静音状态取反） |
| 3-8秒 | 发送`N_S3_REBOT`，S3普通重启 |
| 8秒以上 | 发送`N_S3_ROOT`，S3进入串口刷机模式 |

### 6.2 CPG按钮

| 按下时长 | 行为 |
|----------|------|
| 3-8秒 | 发送`N_S3_ROOT`，S3进入串口刷机模式 |
| 8秒以上 | 发送`N_S3_ROOT`，S3进入串口刷机模式 |

## 7. S3 USB声卡功能

### 7.1 USB音频类

- USB音频设备类（Audio Class 1.0）
- 支持播放和录音
- 采样率：48000Hz，16位立体声

### 7.2 音频数据流

**播放路径：**
```
电脑USB音频 → S3 USB → S3 I2S输出 → E3 I2S输入 → E3 A2DP → 蓝牙耳机
```

**录音路径（蓝牙MIC）：**
```
蓝牙耳机MIC → A2DP → E3 I2S输出 → S3 I2S输入 → S3 USB → 电脑USB麦克风
```

**录音路径（本地MIC）：**
```
INMP441 → E3 I2S输出 → S3 I2S输入 → S3 USB → 电脑USB麦克风
```
