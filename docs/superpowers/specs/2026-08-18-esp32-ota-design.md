# ESP32-S3 WiFi OTA 空中升级示例程序设计

**日期：** 2026-08-18
**状态：** 已批准

---

## 1. 概述

创建一个 ESP32-S3 的 WiFi OTA 示例程序，通过 Web 界面上传固件实现空中升级。设备始终开启 AP 热点作为入口，Web 界面可控制 OTA 功能开关。

## 2. 功能需求

### 2.1 WiFi AP 热点
- 设备启动时自动开启 AP 热点
- SSID 格式：`ESP_OTA_XXXX`（XXXX 为芯片 MAC 地址后 4 位）
- 默认密码：`12345678`
- IP 地址：`192.168.4.1`
- 无密码模式（可选配置）

### 2.2 Web 服务器
- HTTP 服务器监听 80 端口
- 根路径 `/` 返回 HTML 页面
- 支持固件上传接口 `/update`
- 支持状态查询接口 `/status`
- 支持重启接口 `/restart`

### 2.3 Web 界面功能
| 功能 | 说明 |
|------|------|
| OTA 开关 | 启用/禁用 OTA 功能（默认启用） |
| 固件选择 | 文件选择器，仅接受 .bin 文件 |
| 上传按钮 | 触发固件上传 |
| 进度条 | 显示上传进度 |
| 设备状态 | 固件版本、可用内存、运行时间 |
| 重启按钮 | 手动重启设备 |

### 2.4 OTA 更新流程
1. 用户在网页选择 .bin 文件
2. 点击上传按钮
3. ESP32 接收文件并写入 OTA 分区
4. 显示进度条
5. 完成后自动重启（或手动重启）

### 2.5 安全考虑
- OTA 上传期间禁用其他请求
- 上传完成后验证固件完整性
- 错误时回滚到原固件

## 3. 技术方案

### 3.1 开发环境
- **PlatformIO** + **Arduino 框架**
- **开发板**：ESP32-S3-DevKitC-1

### 3.2 核心库
- `Update` — OTA 更新（Arduino 内置）
- `WiFi` — AP 热点
- `WebServer` — HTTP 服务器
- `ESPAsyncWebServer` — 异步 Web 服务器（更好的性能）

### 3.3 分区方案
```
+-------------------+------------+------------+
| Name              | Type       | Size       |
+-------------------+------------+------------+
| nvs               | data       | 20KB       |
| otadata           | data       | 8KB        |
| app0              | app        | 1312KB     |
| app1              | app        | 1312KB     |
| spiffs            | data       | 1280KB     |
+-------------------+------------+------------+
```

### 3.4 文件结构
```
esp32-ota-demo/
├── platformio.ini          # 项目配置
├── src/
│   └── main.cpp           # 主程序
└── data/
    └── index.html         # Web 界面（SPIFFS）
```

## 6. API 接口

### GET /
返回完整的 HTML 页面

### GET /status
返回 JSON 状态信息：
```json
{
  "firmware": "1.0.0",
  "freeHeap": 123456,
  "uptime": 3600,
  "otaEnabled": true
}
```

### POST /update
上传固件二进制文件

### POST /restart
重启设备

### POST /ota-control
控制 OTA 开关
```json
{"enabled": true/false}
```

## 7. 注意事项

1. **固件大小**：确保 .bin 文件不超过 app 分区大小
2. **内存管理**：上传时使用 PROGMEM 存储，避免内存溢出
3. **中断处理**：OTA 升级期间避免长时间中断
4. **电源稳定**：升级过程中不要断电
