# ESP32-S3 WiFi OTA 空中升级实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建一个 ESP32-S3 的 WiFi OTA 示例程序，支持通过 Web 界面上传固件实现空中升级

**Architecture:** 使用 ESPAsyncWebServer 实现异步 HTTP 服务器，设备始终开启 AP 热点作为入口，Web 界面可控制 OTA 功能开关。HTML 页面通过 SPIFFS 存储。

**Tech Stack:** PlatformIO + Arduino框架 + ESPAsyncWebServer + ArduinoJson

## Global Constraints

- 开发板：ESP32-S3-DevKitC-1
- 框架：Arduino
- 分区表：支持 OTA（app0/app1 双分区）
- Web 服务器端口：80
- AP 默认密码：12345678

### Task 7: 主程序整合

**Files:**
- Create: `esp32-ota-demo/src/main.cpp`

```cpp
#include <Arduino.h>
#include "wifi_manager.h"
#include "web_server.h"
#include "ota_handler.h"
#include "web_pages.h"

WiFiManagerClass WiFiManager;
WebServerClass WebServer;
OTAHandlerClass OTAHandler;

void setup() {
    Serial.begin(115200);

    // 初始化 WiFi AP
    String chipID = WiFiManager.getChipID();
    String ssid = "ESP_OTA_" + chipID;
    WiFiManager.begin(ssid.c_str(), "12345678");

    // 初始化 OTA
    OTAHandler.begin(WebServer.getServer());

    // 初始化 Web 服务器
    WebServer.begin();

    Serial.println("OTA Server Ready!");
}

void loop() {
    // 空闲处理
    delay(10);
}
```
