# 高对比度主屏风格重做设计稿

**项目**：my-mx9.0 / lvgl_s3（ESP32-S3-N16R8 + 240×240 ST7789 + lvgl 8.4.0）
**日期**：2026-09-29
**作者**：yyq（设计讨论） + Claude（文档化）
**目标 DISP_MODE**：`DISP_MODE_HIGH_CONTRAST = 6`
**草案方案**：B-1「横向战舰」

---

## 1. 背景与目标

`e29f9a5` 提交的"高对比度风格"是第一版（纯黑背景 + 三段式：上锁柱 / 中时间-键名 / 下温湿）。
本轮要**重做**这版的**摆放位置**和**视觉组织**，让它从"高对比度极简大字"升级为"高端极客的横向驾驶舱"。

保留的展示要素（数量基本不变，只调摆放）：
- 时间（必有大）
- 日期
- 最近按键名（必有大红色）
- 字数 / 累计
- 方案名 + 方案图标
- 温度
- 湿度
- 锁态 NUM / CAPS / SCR（顶栏）

**气质目标**：高端赛车 HUD / 战机驾驶舱 / 仪表盘数据驾驶舱。

---

## 2. 设计原则

| 维度 | 决定 |
|---|---|
| 模块颗粒度 | 2-3 张大卡片 + 1 条横向数据带（不切 4-5 张小卡，也不画细网格分块） |
| 顶栏锁态 | 3 个 LED 圆点 + 下方 NUM/CAPS/SCR 数字 |
| 中部数据带 | KPM（每分钟击键数）+ TODAY（今日击键）+ ACTIVE（活跃时长） |
| 卡片描边 | 1px `CLR_STROKE` 冷色描边（无填色、不画主色发光描边） |
| 键名排版 | 长名缩字号、居中：≤4 字符 48 号，5..8 字符 28 号，>8 字符 20 号 |
| 配色基调 | 冷调单色 + 红警示：黑底 + 青（主信息）+ 绿/琥珀/紫（数据色）+ 红（按键警示） |

## 11. 新增数据计算（实现侧要点，写代码时再细化）

| 字段 | 类型 | 来源 / 算法 |
|---|---|---|
| `keysPerMinute` | uint16_t | 滑动 60s 窗口：环形缓冲区记录最近 60s 每秒落键数，当前 KPM = sum(60s) |
| `todayKeyCount` | uint32_t | 每次按键时若 `currentDay != lastDay` 则清零；持久化（Preferences key `todayKeyCount` + `todayDate`），NTP 校时也清 |
| `idleMinutes` | uint16_t | `(millis() - lastActivityTime) / 60000` |

实现阶段的具体算法（环形缓冲区大小、idle 阈值映射百分比）放到 `writing-plans` 阶段的实施计划里细化。

## 13. 测试要点

实现完成后用户上电验证：
- 切换到此风格后屏卡是否卡死
- 3 个 LED 灯亮灭是否正确随 `locks[3]` 实联动正确
- 大字时间每秒更新（与 NTP 同步）
- 大红键名随按键更新，字符数变化时字号档位正确切换
- KPM 滑动窗口随击键实时变化
- TODAY 数值当日累计、次日清零
- ACTIVE 数值随空闲时间增加、跨小时切换单位
- 方案切换后图标和名称同步
- 长时间运行无内存泄漏（指针清理正确）
