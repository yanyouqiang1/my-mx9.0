2. ME 键文本（下发存储，按 ME 键才发给电脑）

这里下发只是把文本存进键盘，不会立刻在电脑上打字。
存好之后按键盘上的 ME 键，文本才会通过蓝牙打给主机的光标位置。
文本按 UTF-8 转成 hex 存盘，所以中文也能正常发（4.0 起的标准协议）。

1. 按方案按键映射 (REMAP) — 例：把 Win 映射为 Ctrl

映射按方案独立保存，互不影响。底层用的是键盘 HID 键码（HID Usage ID）， 常见修饰键：Ctrl=128, Shift=129, Alt=130, Win/Cmd=131。 按下 MR 录制时进入 NORMAL 模式的键也会走映射，方便游戏改键。

2. 全局独立功能键 (MA / MB / M1~M12)

这里配的是"按下这一颗键，除了按方案宏（M1-M12 才有）外，还会做什么"。 例如 M1 设成"切到方案 2 + Ctrl+Alt+T"，按 M1 会先切方案再发热键。 MA / MB 是纯全局键（没按方案宏），M1-M12 是按方案宏 + 全局动作双层叠加。
所有键将同时按下并释放。可加多个普通键（Num* + Num1 + Num2 全部一起按）
普通键列表（按下时全部一起按）：
字母键发的是小写 a-z，要大写字母请勾上面 Shift；标点 [ ] \ ; ' ` , . / 直接选对应的键。
⚠ 还没添加任何普通键，CMB 没法执行
逐个字符发送（连续输入），可插入 [ENTER]/[TAB]/[ESC]/[BACKSPACE]/SLEEP(ms)

📝 用法说明

协议：GSET:<KEY>:<payload>
payload = "SW:<id>+CMB:<codes>" 或 "SW:<id>+SEQ:<text>"

按键规则：
• MA / MB：纯全局键，按下只跑全局配置
• M1~M12：先跑全局配置，再播按方案宏
• 不配全局动作 → M1-M12 行为与旧版一致（仅按方案宏）

组合键码值：Ctrl=128, Shift=129, Alt=130, Win=131，键位见下方 KEY_OPTIONS

4. BLE 实时日志通道

刷成 USB Keyboard 后 UART0 在大多数电脑上没法再读串口了, 所有 LOG_PORT.printf 的字节改走 BLE notify 回传到这里。 设计很简单:固件按行推,网页按行收,自动滚到底。

开流:实时刷新,适合"我按一下键看路径"。最多 ~50 行/秒,免得把 NimBLE 队列灌爆。
拉历史:把固件 8KB PSRAM 环形缓冲整段拉回来(约 ~80 行最近日志), 缓冲在固件里持久保留到下次开机或点"清空"。
清空:清固件缓冲。注意关流后缓冲**继续在落**,只是不再实时推。
