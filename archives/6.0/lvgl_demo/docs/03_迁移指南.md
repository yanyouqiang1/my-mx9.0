# 迁移指南

## v2.1 → v2.2（时钟 + 中文字体）

### 时钟默认值
`update_clock_ui()` 中的时间判断逻辑已修复：
- **之前**：`tm_year > 120` 在无 NTP 时永远为 false，始终走 else 分支显示 `--:--:--`
- **之后**：`tm_year >= 124`（2024 年），否则显示默认时间 `23:04:06` / `2026-09-26 周六`

### 中文字体
LVGL 现在使用烘焙好的思源黑体 SC 子集（268 字符），不再依赖 Montserrat 内置字体。

#### 改动文件
| 文件 | 改动 |
|------|------|
| `lv_conf.h` | `LV_FONT_CUSTOM_DECLARE` 添加 4 个 `LV_FONT_DECLARE` |
| `lvgl_demo.ino` | 顶部添加 4 个 `#include "../deps/lv_font_sans*.c"`，`build_ui()` 中 Montserrat 替换为 `lv_font_sans*` |
| `bake_fonts.ps1` | 重写，核心修复：改用 `--symbols`（而非 `--range`）传递字符集 |

#### 链接冲突根因（经验记录）

Arduino 会独立编译 sketch 目录下每一个 `.c`/`.cpp` 文件。如果把四个字体 `.c` 放在 sketch 目录下，会被编译四份，链接时报 multiple definition。

**解法**：字体 `.c` 放在 sketch 目录外的 `deps/`，只在 `.ino` 里用 `#include` 引进来（不独立编译）。

如果 bake_fonts.ps1 的输出目录改了（从 `lvgl_demo/` 改到 `deps/`），记得同步更新 `bake_fonts.ps1` 里的 `$OUT_DIR` 变量。

#### 重新烧录
烧录后验证：
1. 屏幕应显示 `23:04:06` 或正常时间（不应该是 `--:--:--`）
2. 日期 `2026-09-26 周六` 或实际日期，中文应正常显示（不是方框）
