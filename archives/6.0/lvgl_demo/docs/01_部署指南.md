# LVGL 大字时钟 Demo — 部署指南

## 📋 文件清单

```
lvgl_demo/
├── lvgl_demo.ino             ← Arduino 主入口（setup/loop 在这里）
├── lvgl_st7789_driver.h      ← LVGL ↔ ST7789 适配层头文件
├── lvgl_st7789_driver.cpp    ← LVGL ↔ ST7789 适配层实现
├── lv_conf.h                 ← LVGL 配置（字体/控件开关都在这里调）
├── deps/                     ← 思源黑体 SC 子集（sketch 外，避免重复编译）
│   ├── lv_font_sans16.c
│   ├── lv_font_sans20.c
│   ├── lv_font_sans28.c
│   └── lv_font_sans_bold48.c
└── docs/
    ├── 02_字体方案.md         ← 思源黑体子集烘焙方法
    └── 03_迁移指南.md         ← 把现有 6 屏迁移到 LVGL 的步骤
```

**字体文件（`deps/`）说明**：放在 sketch 目录外，Arduino 不会独立编译它们，只在 `lvgl_demo.ino` 里用 `#include` 引进来一次，避免链接时 multiple definition 错误。

## ⚙️ Arduino IDE 一次性配置

### 1. 安装 ESP32 内核

> 文件 > 首选项 > 附加开发板管理器 URL：
> ```
> https://espressif.github.io/arduino-esp32/package_esp32_index.json
> ```
> 工具 > 开发板 > 开发板管理器 → 搜 "esp32" → 装 **esp32 by Espressif Systems** (v2.0.14 或更高)

### 2. 安装依赖库

> 工具 > 管理库... → 搜下面的，**版本号严格匹配**：

| 库名 | 版本 | 备注 |
|---|---|---|
| **lvgl** | **8.4.0**（不要装 v9，API 不一样） | 库管理器搜 "lvgl"，作者是 kisvegabor |
| Adafruit ST7789 Library | 1.7.x | 默认最新版即可 |
| Adafruit GFX Library | 1.11.x | ST7789 的依赖 |

### 3. 启用 LVGL 配置头文件

LVGL 默认安装后**所有功能都是关闭的**，需要把 `lv_conf_template.h` 改名为 `lv_conf.h` 并改配置。

**方法 A（覆盖法，推荐）**：

1. 找到 LVGL 库的安装位置。Windows 一般在：
   ```
   C:\Users\<你>\Documents\Arduino\libraries\lvgl\
   ```
2. 把我们提供的 `lv_conf.h` 复制到 `lvgl/` 目录下，**覆盖**它原本的 `lv_conf_template.h`（如果它已经叫 `lv_conf.h`，先删掉旧的）。
3. 打开我们提供的 `lv_conf.h`，确认第 16 行 `#define LV_HOR_RES_MAX 240` 没有被注释掉。

**方法 B（保持库文件不动）**：

1. 把 `lv_conf.h` 放到 `lvgl/src/lv_conf.h`
2. 编辑 `lvgl/lvgl.h`，在最顶上加 `#define LV_CONF_SKIP` 之前的某行加 `#define LV_CONF_INCLUDE_SIMPLE` 然后包含 `lv_conf.h` 路径

**99% 的情况用方法 A 就行**。

### 4. 开发板配置

> 工具 > 开发板：**ESP32S3 Dev Module**

然后关键开关（在 Tools 菜单里）：

| 项 | 值 |
|---|---|
| USB CDC On Boot | Enabled（方便看串口） |
| CPU Frequency | 240MHz |
| Flash Mode | QIO 80MHz |
| Flash Size | **16MB (128Mb)** ← 必须选这个 |
| Partition Scheme | **16MB Flash (3MB APP/9.9MB FATFS)** ← 必须选这个，给 FFat 留 9.9MB |
| PSRAM | **OPI PSRAM** ← **核心开关，不开就 OOM** |
| Upload Speed | 921600 |

## 🔧 常见问题排查

### Q1: 编译报错 `lv_conf.h: No such file`
**A**: 没启用 lv_conf.h。回到"步骤 3"，确认 `lv_conf.h` 在 `libraries/lvgl/` 下被改名为 `lv_conf.h`（不是 `lv_conf_template.h`）。

### Q2: 编译报错 `Adafruit_ST7789: writePixels not declared`
**A**: Adafruit_ST7789 库版本太老。打开库管理器升级到 1.7+。或者驱动代码里有 `#if defined(ARDUINO_ADAFRUIT_ST7789_HAS_WRITE_PIXELS)` 兼容分支，会自动用 `pushColors`。

### Q3: 烧录后屏幕是黑的
**A**: 串口看是不是 `[WARN] PSRAM 没启用`。如果是这样：
- Arduino IDE: Tools > PSRAM > **OPI PSRAM**
- 重启 IDE 重新烧录

### Q4: 串口显示 `[LVGL] FATAL: no memory for framebuffer`
**A**: framebuffer 分配失败，两个原因：
- PSRAM 没开（看 Q3）
- `LV_MEM_SIZE` 设太大（64KB），8MB PSRAM 不会触发；内部 heap 才有可能 → 调小到 32KB 测试

### Q5: 中文显示为方框 / 问号
**A**: 检查 `lvgl_demo.ino` 顶部是否已有 `#include "../deps/lv_font_sans*.c"` 四行。fonts 已烘焙好（思源黑体 SC 268 字符子集），集成方式见 `docs/02_字体方案.md`。如果字符不在子集内（如罕见字），需要重新烘焙扩展字符集。

### Q6: 时间显示 "等待同步时间..."
**A**: ESP32 没接 RTC，没跑 NTP。Demo 里的 `time(nullptr)` 是默认 1970 起的 epoch。这不影响视觉效果，**只是让你确认 LVGL 的时间刷新定时器在工作**（每秒会触发 `update_clock_ui`，你能看到串口字符变化的话 LVGL 调度就 OK）。

正式接入项目时，从 s3.ino 把时间同步逻辑（NTP / 网页下发 / 串口下发）搬过来。

### Q7: 屏幕刷新很卡 / FPS 低
**A**: `lvgl_demo.cpp` 里 `#define BUF_LINES 40` 是保守值。改到 60/80 会更顺，但多占 PSRAM。

## 📊 资源占用预估

| 项 | 占用 |
|---|---|
| LVGL 静态代码 | ~250 KB Flash |
| LVGL 对象池 (LV_MEM_SIZE) | 64 KB PSRAM |
| Framebuffer (单缓冲) | 19.2 KB PSRAM |
| demo 控件对象 | < 5 KB PSRAM |
| 思源黑体 4 档子集 | ~1.77 MB Flash |
| **合计** | **~83 KB PSRAM / ~2 MB Flash** |

N16R8 有 16MB Flash + 8MB PSRAM，**用了约 12% 的 Flash**，剩下全留给你的项目代码、JPEG 解码、SHT31 等。
